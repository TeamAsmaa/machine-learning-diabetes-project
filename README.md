# Machine Learning Diabetes Project

A machine learning project that predicts diabetes outcomes using the Pima Indians Diabetes dataset. The notebook covers data preprocessing, outlier handling, standardization, and training/comparison of six classification models.

## Project Structure

```
machine-learning-diabetes-project/
│
├── dataset/
│   ├── diabetes.csv            # raw dataset
│   └── cleaned_dataset.csv     # cleaned/processed dataset (generated, gitignored)
│
├── diabetes_prediction_models.ipynb
├── requirements.txt
├── README.md
└── .gitignore
```

## Workflow

The notebook (`diabetes_prediction_models.ipynb`) is organized into the following sections:

### 1. Imports
Loads `pandas`, `numpy`, `matplotlib`, `seaborn`, and the relevant `scikit-learn` modules (`MinMaxScaler`, `train_test_split`, classification metrics, and the model classes listed below).

### 2. Load Dataset
Reads `dataset/diabetes.csv` into a DataFrame.

### 3. Preprocessing
General exploration of the dataset: shape, data types, summary statistics (`describe`), `info()`, column names, and class balance (`groupby('Outcome')`).

### 4. Visualizations
- Pie chart of the `Outcome` class distribution
- Unique value counts per column
- Histograms for all features
- Scatter matrix of all features

### 5. Data Cleaning
- Checks for null values
- Drops duplicate rows
- Correlation heatmap of the dataset

### 6. Outlier Handling
Several columns (`Glucose`, `BloodPressure`, `SkinThickness`, `Insulin`, `BMI`) use `0` as a placeholder for missing values. These are:
1. Replaced with `NaN`
2. Filled with the median of the corresponding `Outcome` group
3. Remaining outliers clipped using the IQR method (no rows dropped)

Before/after box plots are generated for all numeric columns to visualize the effect.

### 7. Standardization
All numeric features are scaled with `MinMaxScaler`, and the cleaned data is saved to `dataset/cleaned_dataset.csv`.

### 8. Train/Test Split
The cleaned dataset is split into features (`X`) and target (`y`, the `Outcome` column), then split 80/20 into train and test sets (`random_state=42`).

### 9. Model Training & Evaluation
The following models are trained and evaluated individually, each reporting **accuracy, precision, recall, F1-score, confusion matrix, and classification report**:

- Logistic Regression
- Decision Tree (with a plotted tree visualization)
- Gradient Boosting
- Random Forest
- Support Vector Machine (SVM)
- Neural Network (`MLPClassifier`, hidden layers `(64, 64)`, `max_iter=500`)

### 10. Model Comparison
- A bar chart comparing accuracy scores across all six models
- A final loop that re-trains all models together and prints/plots evaluation metrics and confusion matrices for each

## Notes

- `dataset/cleaned_dataset.csv` is generated by running the notebook and is excluded from version control via `.gitignore`.
- Random state is fixed at `42` for reproducibility across the train/test split and applicable models.
